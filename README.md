# Көшірме

Қазақ тіліндегі цифрлық пираттық туралы 11 слайдтық веб-презентация.

Слайдтар: сырғыту, көрсеткі пернелер, Page Up / Page Down, Home / End және навигация батырмалары. «Мазмұн» барлық слайдты ашады; «Түсіндірме» баяндамашыға арналған мәтінді көрсетеді. Сценарий бағалары тек ағымдағы бет жадында сақталады, ешқайда жіберілмейді.

Негізгі дерек: Qazpatent сауалнамасы, 2023, N = 19 088. Зерттеу материалы: `piracy_research_final.docx`. Жиынтық деректер жеке адам деңгейінде байланыстырылмайды. Бейресми көз, тегін платформа және заңсыз контент бірдей санат емес.

## Local preview

Open `index.html` directly, or serve this directory with any static HTTP server. No build or package installation is needed. All font, graphic, and animation assets are local. Reduced motion is respected.

## GitHub Pages

Upload this directory's contents to a dedicated repository. In Settings → Pages choose Deploy from a branch → main → / (root). `.nojekyll` prevents Jekyll processing. Relative asset links support project Pages URLs.

## Assets

Fonts: Golos Text and Unbounded, SIL Open Font License (copies in `assets/`). Animation: GSAP 3.13.0 and Observer, https://gsap.com/standard-license/. Disc cover: original asset generated with the built-in image generation tool. Prompt: a silver optical compact disc with a physically rippled edge and detached fragments, transparent background, hard flash editorial still life, restrained cobalt and acid-yellow reflections; no text or data.
